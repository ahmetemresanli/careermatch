# CareerMatch

CareerMatch is a smart career platform that connects job seekers and employers through **job-candidate matching**.

The platform aims to provide more than a traditional job board by offering verified professional profiles and recruitment management features.

## Main Features

* Candidate and company profiles
* Job posting and application management
* Candidate ↔ Job matching and recommendations
* Similar job recommendations
* Verified education and employment history
* Professional reference system
* Candidate–company messaging
* Interview management
* Notifications
* Company reviews and recent news

## Tech Stack

**Backend**

* Java
* Spring Boot
* Spring Data JPA
* Spring Security
* PostgreSQL

**Other**

* REST API
* JWT
* Docker
* Git / GitHub
